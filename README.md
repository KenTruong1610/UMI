## ĐỒ ÁN TỐT NGHIỆP - UEH Media Intelligence & Reputation Monitoring

Hệ thống phân tích các tình huống trên không gian mạng dành cho UEH

### 🔹 Dashboard
- ⭐ Thể hiện thông tin các báo cáo (Tích cực, Trung Bình, Tiêu Cực)
- ✨ Sử dụng LLM để xử lý thông tin
- 🎨 Dự liệu được lưu trên MongoDB

### 🔹 Các chức năng chính
- **Xử Lý Thông Tin thông qua LLM:** Hệ thống dùng kiến trúc LLM để phân tích dữ liệu từ các bài báo thông qua cào dữ liệu và NLP để bóc tách phân tích ngữ nghĩa
- **Giao diện ban đầu:** Thống kê và sử dụng các thông tin để train cho các thông tin kế tiếp
- **Dữ liệu lưu trữ:** Sử dụng MongoDB để lưu trữ dữ liệu để phân tích

---

## ⚙️ Tải về

1. Tải VS Code về.
2. Dùng Git để tải repository:
   ```bash
   https://github.com/KenTruong1610/UMI.git
   ```
3. Vào terminal và viết
   ```bash
   npm start để khởi động
   ```
4. Vào localhost:3008 để vào hệ thống

---

## Dữ liệu
Danh sách các bài báo được lưu vào MongoDB và có thể tải thông qua Json/CSV. Dữ liệu được xử lý và ghi trong cơ sở dữ liệu. Báo cáo truy vấn dữ liệu theo thời gian, Nội dung và lọc.
